# «Маленький принц» — лендинг детской парикмахерской (Красноярск)

Одностраничный сайт детской студии красоты «Маленький принц»: стрижки, прокол ушей System-75, праздничные причёски. ул. Капитанская, 14.

## Структура

```
index.html          — страница (11 блоков, JSON-LD HairSalon + FAQPage)
css/style.css       — стили
js/script.js        — меню-бургер, табы цен, слайдер отзывов, галерея, капсулы, FAQ
img/                — фото в WebP + JPG (640 и 1200 px), логотип, иконки, og-image
favicon.ico, site.webmanifest
robots.txt, sitemap.xml — SEO
llms.txt            — GEO (для ИИ-поисковиков: ChatGPT, Алиса, Perplexity)
```

## Блоки

1. Первый экран  2. Четыре направления  3. Первая стрижка (маршрут + совет про будни + капсулы-подарки)  4. Цены (табы)  5. Прокол ушек  6. Интерьер (горизонтальная галерея)  7. Работы  8. Мастера  9. Отзывы (слайдер)  10. FAQ  11. Контакты + Яндекс.Карта

## Перед публикацией

- Замените домен `https://prince-krsk.ru/` на реальный в `index.html` (canonical, og:url, og:image, JSON-LD), `robots.txt`, `sitemap.xml`.
- Проверьте часы работы (указано 10:00–20:00 ежедневно).
- Загрузите папку целиком на хостинг; сборка не требуется.

## Совместимость

Chrome, Safari (iOS 13+), Firefox, Edge, Samsung Internet, Яндекс.Браузер. Учтены safe-area для iPhone с «чёлкой», WebP с JPG-фолбэком, отключение анимаций при `prefers-reduced-motion`.
